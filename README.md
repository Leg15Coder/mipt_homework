# Документация к ДЗ

Данный проект реализует REST API и веб-страницы на основе Freemarker для управления статьями и комментариями блога. API поддерживает операции создания, чтения, обновления и удаления статей и комментариев. Freemarker используется для отображения статей и комментариев в HTML.

---

### REST API

#### 1. **Получить все статьи**
- **URL:** `GET /api/articles`
- **Описание:** Возвращает список всех статей.
- **Ответ:**
    - `200 OK` — если есть данные.
    - `500 Internal Server Error` — в случае ошибки.

#### 2. **Получить статью по ID (с комментариями)**
- **URL:** `GET /api/articles/:id`
- **Описание:** Возвращает статью и связанные с ней комментарии по ID.
- **Ответ:**
    - `200 OK` — со всеми данными статьи.
    - `404 Not Found` — если статья не найдена.
    - `500 Internal Server Error` — в случае ошибки.

#### 3. **Создать статью**
- **URL:** `POST /api/articles`
- **Описание:** Создает новую статью.
- **Тело запроса:**
    - JSON с полями `header` (заголовок, строка) и `tags` (список тегов).
- **Ответ:**
    - `201 Created` — с ID созданной статьи.
    - `409 Conflict` — если статья с такими параметрами уже существует.
    - `500 Internal Server Error` — в случае ошибки.

#### 4. **Обновить статью**
- **URL:** `PUT /api/articles/:id`
- **Описание:** Обновляет существующую статью по ID.
- **Тело запроса:**
    - JSON с полями `header`, `tags` и `comments`.
- **Ответ:**
    - `204 No Content` — при успешном обновлении; тело ответа пустое.
    - `404 Not Found` — если статья не найдена.
    - `500 Internal Server Error` — в случае ошибки.

#### 5. **Удалить статью**
- **URL:** `DELETE /api/articles/:id`
- **Описание:** Удаляет статью по ID.
- **Ответ:**
    - `200 OK` — при успешном удалении.
    - `404 Not Found` — если статья не найдена.
    - `500 Internal Server Error` — в случае ошибки.

#### 6. **Добавить комментарий**
- **URL:** `POST /api/comments`
- **Описание:** Добавляет комментарий к статье.
- **Тело запроса:**
    - JSON с полями `article` (ID статьи) и `text` (содержимое комментария).
- **Ответ:**
    - `201 Created` — с ID созданного комментария.
    - `400 Bad Request` — если запрос некорректен.
    - `500 Internal Server Error` — в случае ошибки.

#### 7. **Удалить комментарий**
- **URL:** `DELETE /api/comments/:id`
- **Описание:** Удаляет комментарий по ID.
- **Ответ:**
    - `200 OK` — при успешном удалении.
    - `404 Not Found` — если комментарий не найден.
    - `500 Internal Server Error` — в случае ошибки.

### Шаблоны Freemarker

#### 1. **Главная страница**
- **URL:** `GET /`
- **Описание:** Показывает список статей с их тегами, количеством комментариев и ссылками на статьи.
- **Шаблон:** `index.ftl`

#### 2. **Просмотр статьи**
- **URL:** `GET /article/:id`
- **Описание:** Отображает информацию о статье и список комментариев.
- **Шаблон:** `article.ftl`
